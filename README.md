## 一、项目概述

### 1.1 项目定位
**DeskAura** 是一款面向 Windows 生态的 **Local-First（本地优先）3D 虚拟数字人桌面智能体**。  
我们深度结合了轻量化系统底座（Tauri 2.x + Rust）、现代 3D 渲染管线（Three.js + three-vrm）以及高度解耦的端侧微服务架构（FastAPI 编排 + MemU 记忆图谱 + 本地动作引擎），让桌面数字生命彻底摆脱“必须连外网、高频消耗云端算力、数据时刻面临外泄风险”的传统弊端。

用户导入任意合规的 `.vrm` / `.glb` 3D 角色模型，即可在 Windows 桌面上拥有一个具备**眼神交互、情绪感知、动作表达、记忆沉淀与工具辅助**的专属数字伴侣。

### 1.2 核心痛点与行业解答

| 行业常见产品痛点 | DeskAura 创新解答方案 |
| :--- | :--- |

## 二、应用场景

### 场景一：极客工位全天候沉浸伴侣
* **工作流**：开发者在双屏或超宽屏编写代码时，DeskAura 安静驻留在屏幕边缘。当使用者转头望向屏幕角落时，内置的 BlazeFace 算法捕获视线焦点，角色头部与眼球自然转动与用户产生“眼神对视”；双击角色呼出轻量对话浮窗，即可协助查询技术资料或沉淀当日常用备忘。
* **核心价值**：提供高拟真、不阻断工作流的“陪伴感”与“工位心理支持”。

### 场景二：完全离线 / 内网高保密场景陪伴
* **工作流**：在无互联网接入的内网实验室或保密办公机上，DeskAura 运行在纯离线模式。通过本地 SenseVoice ONNX 完成语音分句识别，借助端侧嵌入模型（BGE-small）检索本地 Markdown 知识库，驱动 25 组离线动作库完成流畅的情绪表达与回答。
* **核心价值**：严格遵守数据安全防线，零网络开销，无泄密风险。

### 场景三：二次元 / 数字人创作者资产热插拔平台
* **工作流**：3D 建模师与 VTuber 创作者制作好 `.vrm` 或 `.glb` 模型后，无需编写任何 Unity 或 UE 逻辑，直接拖拽入 DeskAura，系统自动完成骨骼重定向、头部形变绑定与材质优化，并支持为该角色单独配置独立人设 System Prompt 与记忆库。
* **核心价值**：大幅降低 3D 虚拟人交互落地门槛，赋能创作者生态。

### 3.2 核心业务流程：单次交互与记忆沉淀闭环

1. **感知与唤醒**：摄像头端侧捕获人脸姿态角（Yaw / Pitch），Kalidokit 实时反解为颈椎与眼球旋转量，驱动数字人眼神对齐；
2. **意图解析与规划**：用户输入自然语言（键盘或离线语音 ASR），请求递交至 8000 端口 Agent；编排器提取意图分类，并异步向 8001 记忆微服务检索相关历史背景；
3. **分句流式输出**：大模型生成回复文字，系统按照标点进行分句（SentenceBuffer），首句生成后立即调用端侧 TTS 进行流式播放，显著降低首字等待时延（TTFT < 400ms）；
4. **具身动作匹配**：8002 动作引擎根据情感意图（如 happy, serious, thinking），从动作库中检出对应骨骼动画指令，下发至 Three-VRM 渲染帧序列；
5. **记忆持久化沉淀**：交互结束后，记忆微服务对当轮对话提取总结（Insight），写入当前角色独立命名空间的 SQLite 与向量数据集中。

## 五、评测标准与实测数据

### 5.1 端到端跑通率与意图鲁棒性
* **基准测试集**：构建涵盖 20 个日常多轮对话与动作指令的测试用例（包括情绪表达、技术咨询、记忆召回、复杂工具调用等）。
* **测试结果**：**20/20 全部一次性跑通**。在网络断开（离线模式）下，系统自动平滑降级至本地知识库与预置动作，未触发任何崩溃或空指针异常。

### 5.2 视线追踪与骨骼平滑度
* 对比裸跑 OpenCV 人脸检测与 MediaPipe + Kalidokit 方案：传统检测在弱光环境下抖动幅度超过 12%，DeskAura 引入 **CameraLease 双焦点指数平滑滤波（Exponential Smoothing）**，将抖动量压制在 0.8% 以内，实现丝滑灵动的眼神注视。

## 六、技术实现与创新点

### 创新点一：Win32 深度定制与恒定包围球技术 (`CameraBounds.ts`)
不同于常规网页打包工具，DeskAura 使用 Rust 原生操纵 Windows 窗口消息句柄（`HWND`），通过设置 `WS_EX_LAYERED` 与透明混合通道，实现真正在桌面背景上“无缝悬浮”。独创 `CameraBounds` 算法，在模型加载时自动计算 3D 几何包围球半径并锁死交互边界，彻底杜绝了模型在滚轮放大或窗口拖动时穿模、出画或形变的历史难题。

### 创新点二：端侧 WASM 视线捕获与硬件生命周期安全隔离 (`CameraLease`)
在桌面端引入 MediaPipe BlazeFace WASM 计算管线，全部推断跑在浏览器内核本地缓存中，无需将画面回传后端，保障物理层面的隐私安全。配套设计 `CameraLease` 租约状态机：当用户将标签页切至后台或最小化角色时，立即触发底层 `track.stop()`，不仅杜绝隐私担忧，更大幅降低待机功耗。

### 创新点三：轻量解耦微服务拓扑与端口契约隔离
系统将后端逻辑清晰切分为 8000（对话编排）、8001（记忆沉淀）与 8002（动作姿态）三大自治服务。各服务之间通过轻量 HTTP/JSON 契约通信，任何单一服务的升级或故障均不影响 3D 渲染主进程的稳定存活，极具工业级扩展性。

### 创新点四：25 组精校动作库与防死锁 4 节点待机状态机
针对开源界“生成全身动作需消耗 24GB 显存”的痛点，创新性地提前沉淀并工程化标定了 25 组覆盖各类典型情绪的 3D 骨骼动作文件。待机调度器依据泊松分布在“活跃待机 -> 离开观察 -> 打瞌睡 -> 随机交互”之间自然流转，无需高端独立显卡即可呈现极具生命力的微动作。

## 八、社会价值与安全合规

1. **零数据出域的隐私安全承诺**：在 AI 时代，桌面与摄像头属于极度敏感的用户私人领域。DeskAura 坚守 Local-First 原则，所有视线画面、生物特征和会话记录均由本地硬件即时消化，为智能伴侣领域的隐私合规树立标杆。
2. **数字心理慰藉与工位健康**：在快节奏、高强度的现代研发工作中，温和友善的桌面数字伴侣能够有效缓解工作焦虑与孤独感，提供正向情绪价值。
3. **模型合规边界**：应用开箱即用内置两款合规开源 VRM 模型「结海 (Yuika)」（作者 minto_akayama / VRoid Hub 强制署名许可）与「千駄ヶ谷渋 (Shibu)」（作者 VRoidプロジェクト / 官方示例模型许可），附带完整第三方署名与授权链接（THIRD_PARTY_LICENSES.txt），确保分发与评测 100% 版权合规。
